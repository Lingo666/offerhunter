# 一页项目走读卡

暂停时填到当前位置，下次沿用同一张卡。用自己的话写判断。代码位置写仓库相对路径和函数，方便换电脑后再找。

| 本轮记录 | 我填写的内容 |
| --- | --- |
| 项目与版本 | 项目名、分支或版本 |
| 我选的功能 | 做一个什么动作，预期看见什么 |
| 我的主链 | 输入 → 谁接收 → 谁改变数据 → 谁给出可观察的结果 |
| 进度 | Q__ / __，下一次从 ______ 开始 |

| 我能解释的交接 | 我拿出的证据 | 本次表现 |
| --- | --- | --- |
| 谁把什么交给谁 | 文件和函数、测试断言或运行记录 | 还需示范／提示后做到／换题独立完成 |

- 我原先以为 ______，看到 ______ 后，把判断改为 ______。
- 要补的一个知识点是 ______。它用在 ______，改变 ______ 后，可以观察 ______。
- 收课的新条件是 ______。我预测 ______，依据是 ______，还可以用 ______ 验证。
- 暂时留到课后的一个问题是 ______。

新开对话时贴上这张卡，说「从上次未验证的地方继续，先让我预测」。若上次已收课，就把要复查的地方作为新一轮的起点。
